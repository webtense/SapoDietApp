# UX/UI y Flujos

## Flujo principal

1. Login/registro.
2. Onboarding en 5 pasos con validaciones.
3. Generacion de plan nutricional y de ejercicios.
4. Lista de compra semanal.
5. Seguimiento diario de comidas/ejercicios + check-in.

## Mejoras aplicadas

- Validacion por pasos antes de avanzar.
- Inclusión de sexo para calculo calorico realista.
- Mensajes de viabilidad de meta con orientacion accionable.
- Fondo y visuales mas intencionales para reducir sensacion de "formulario plano".
- Check-in diario (agua, peso, energia, animo) inspirado en apps de adherencia.

## Heuristicas de usabilidad

- Visibilidad del estado del sistema: barra y porcentaje de paso.
- Prevencion de error: bloqueo de avance con datos faltantes.
- Control del usuario: navegacion Anterior/Siguiente y ajuste posterior.
- Consistencia: nomenclatura y acciones uniformes entre modulos.

## Proxima mejora UX recomendada

- Vista calendario semanal.
- Recordatorios de comidas/entreno.
- Modo "hoy" con acciones prioritarias en primer pliegue.
