# Libro de Estilos

## Identidad visual

- Tema: bienestar y adherencia saludable.
- Direccion cromatica: verdes suaves con fondo claro y contraste legible.
- Sensacion buscada: calmada, estructurada y accionable.

## Tipografia

- Primaria: Geist Sans.
- Mono/tecnica: Geist Mono.
- Jerarquia:
  - H1: 2.25rem bold.
  - H2: 1.875rem semibold/bold.
  - Texto base: 1rem.
  - Auxiliar: 0.875rem.

## Espaciado y layout

- Escala base: 4px.
- Contenedores:
  - Formularios: max 2xl.
  - Paneles de resultado: max 4xl/5xl.
- Cards con `shadow` suave y borde verde tenue.

## Componentes

- Botones:
  - Primario para acciones de avance.
  - Secundario para acciones de soporte.
  - Outline para navegacion o regreso.
- Badges para progreso y estado.
- Barras de progreso para completar onboarding y listas.

## Estados UX

- Error validacion: fondo rojo suave, texto rojo oscuro.
- Confirmacion: verde suave.
- Meta ambiciosa: ambar suave (sin bloquear flujo).

## Responsive

- Mobile-first.
- Grids de una columna que escalan a 2-4 columnas en `md`.
- Acciones principales visibles sin scroll excesivo.
