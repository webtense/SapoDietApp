# Documentacion de SapoFit

Esta carpeta centraliza toda la documentacion funcional, tecnica y de despliegue del proyecto.

## Indice

- `arquitectura.md`: arquitectura general, modulos y decisiones tecnicas.
- `estilos.md`: libro de estilos visuales y patrones de componentes.
- `ux-ui.md`: flujos de usuario, principios de usabilidad y mejoras aplicadas.
- `datos.md`: modelo de datos con Prisma y estrategia de migraciones.
- `api.md`: contratos de API, payloads y respuestas.
- `seguridad.md`: autenticacion, sesiones, buenas practicas y hardening.
- `despliegue.md`: ejecucion local y despliegue posterior en EasyPanel.
- `roadmap.md`: backlog priorizado de evolucion del producto.

## Alcance actual

- Aplicacion funcional en local con Next.js + Prisma + SQLite.
- Autenticacion por email y contrasena con hash seguro.
- Persistencia de perfil, plan, seguimiento y lista de compra.
- Interfaz renovada para mejor claridad y flujo de onboarding.
